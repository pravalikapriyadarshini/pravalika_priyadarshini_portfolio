# Pravalika's Portfolio Website

A responsive, dark editorial-style personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.
3. For editing, open the folder in VS Code or another text editor.

No Python, database, or backend is required for this static version.

## Personalize before publishing
- Your email, LinkedIn, and GitHub links have been personalized.
- Your resume PDF is included at `assets/resume.pdf`; the resume buttons open it.
- Review project descriptions and links before publishing; add repository/live-demo links when available.
- Add a real profile photo if you want to use one instead of the monogram.
- Consider adding project repository/live-demo links.

## Publish it for anyone to visit
This static site can be published with GitHub Pages, Netlify, or Vercel. The ZIP itself is not a live website; publishing is a separate step.

## Files
- `index.html` — content and page structure
- `style.css` — visual design, layout, responsive styles
- `script.js` — mobile navigation and current year
